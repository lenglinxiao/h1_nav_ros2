# 原导航网页栏内滚动

- 目标：窗口高度不足时，设置、任务、控制和日志区域仍可通过可见滚动条查看完整内容。
- 范围：三列纵向滚动；中间任务内容独立纵向滚动；路线表保留横向滚动；窄屏继续提供栏内滚动；滚动条样式清晰且可拖动。
- 非目标：调整页面信息架构、改变任务/控制逻辑或部署到真机。
- 状态：本地实现完成。桌面断点设置三栏独立 overflow；窄屏断点保留栏内最大高度与滚动；增加 Chromium/WebKit 和 Firefox 滚动条样式。
- 验证：`python3 -m pytest -q test/static/test_h1_2_nav_web_gui.py` 34 passed；GUI Python 编译、内嵌 JavaScript `node --check`、`git diff --check` 通过。1440×700 与 1100×700 本机页面预览 HTTP 200，滚动区域在两种布局下均保留。
