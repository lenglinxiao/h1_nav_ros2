## 目标与范围

保留现有定位、地图、Nav2 路径规划和速度平滑，将运动执行切换至 ONNX 策略，并通过分阶段真机验收建立可追溯的运动与导航基线。范围涵盖已有接口的联调、停止和恢复行为，以及必要的导航参数调整；不以本计划重写 Nav2、修改模型或 PD 增益、扩展既有速度限制，也不关闭状态、速度、急停或撤权保护。

拟议链路（尚未实现）：

```text
定位 / 地图 → Nav2 → /cmd_vel → velocity_smoother_ema
→ 会话 cmd_vel → coordinator → /h1_2/policy/cmd_vel → h1_2_policy_bridge → ONNX → rt/lowcmd
                                                                  ↑ rt/lowstate
```

已有 `motion_backend:=policy`、连续策略模式和 [policy_navigation_gate](../../src/h1_2_nav_tools/h1_2_nav_tools/policy_navigation_gate.py)。两个导航 action 的代理转发、取消与 ready 失效行为已用隔离假节点验证；这不是实际导航验收。接口和已有限速、超时说明见 [策略桥 README](../../src/h1_2_policy_bridge/README.md)。`/h1_2/policy_ready` 是软件就绪信号，不证明现场平衡或控制权独占。
