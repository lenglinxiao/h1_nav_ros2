## 🔧 如果手指有问题

### 问题1：手指不动

**可能原因**：
- Dex5话题名不对
- Dex5服务未正常运行
- 手指增益太小

**排查**：
```bash
# 在PC4上检查话题是否有数据
ros2 topic echo /dex5/right/cmd
```

### 问题2：手指动作太慢或太快

**调整**：编辑配置文件增益
```yaml
# 在 grab_pull.yaml 中（未来版本）
dex5:
  finger_gains:
    kp: 0.10  # 增大=更快响应
    kd: 0.001
```

### 问题3：握拳太紧或太松

**调整**：修改握拳角度
```cpp
// 在 arm_gesture_player.hpp:288
double fist_angles[20] = {
  0.0, 1.25, 1.33, 1.13,  // 减小这些数字=握得更松
  ...
};
```
