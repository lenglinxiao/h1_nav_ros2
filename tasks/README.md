# 任务交接约定

跨会话或多步骤工作使用一个任务文件；普通对话无需创建。新任务复制下方模板至 `tasks/YYYYMMDD-简短标识.md`，以文件名作为稳定 ID；不用全局计数，创建前检查是否重名。`SESSION.md` 只索引活动任务和最近完成任务，任务文件是状态事实源。

状态：`待处理`（尚未开始）、`进行中`（有人认领）、`阻塞`（写明阻碍和解除条件）、`待验收`（实现及必要验证完成，等待验收）、`完成`（完成条件满足）。认领和文件范围是协作约定，不是原子锁；并发时先检查，发生冲突保留分歧并报告。最新用户指令优先，历史授权不能自动延续；已有授权的范围、次数及有效条件仍需准确记录和遵守。

说“同步 session”时更新任务状态及必要索引；“继续任务 <ID>”时先读对应任务、检查工作区，再按最新指令执行。验证记录写命令、结果、对应代码和环境、证据路径；未保存 hash 写无。日志只追加关键决策、失败原因和交接，不复制聊天或秘密。

## 可复制模板

```markdown
# 任务：<ID>

- 状态：待处理
- 更新时间：<日期时间和时区>
- 负责人 / 认领：无；文件范围：<路径>
- 目标：<目标>
- 范围：<范围>
- 非目标：<非目标>
- 依赖：<依赖或无>
- 当前摘要：<完成情况、阻碍和未解决事项>
- 下一步：<可执行步骤>
- 完成条件：<可验证条件>
- 授权边界：<范围、次数、有效条件或无；现场状态须复核>

## 验证

- 命令：<命令或未运行>；结果：<结果>；代码和环境：<对应状态、hash 或无>；证据：<路径或无>。

## 交接日志

- <日期时间>：<关键决策、失败原因或交接>。
```
